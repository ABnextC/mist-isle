# 안개섬 개척기 (가제)

지도에 없던 섬에 상륙한 개척자가 채집·정제·제작으로 섬의 경제를 세우고, 그 물건으로 싸우는 MMORPG 웹게임.
싱글플레이로 먼저 완성하고, 같은 규칙 위에 멀티플레이를 얹는다.

- **게임(3D)**: `index.html` — 깃허브 페이지를 켜면 https://abnextc.github.io/mist-isle/ 에서 열린다
- **엔진 점검판**: `debug.html` — 명령을 하나씩 눌러 보는 화면
- **패치노트**: `patchnotes.html` (페르소나 후기 포함)
- **진행 현황**: [`docs/progress.md`](docs/progress.md)
- **페르소나 플레이 원본**: [`docs/playtests/`](docs/playtests/)
- **설계 문서**: Claude 프로젝트 「게임 개발」의 `claude/life-mmo-design.md` (이 저장소에는 없다)

## 실행

```bash
node tools/test.js                                    # 테스트
node tools/personas.js --days 7 --seed 2026           # 페르소나 7명 자동 플레이 (--json 가능)
node tools/campaign.js                                # 진행 페르소나 7명: 1~6장 메인·서브 완주 (--only 이름, --json)
node tools/headless.js --days 3 --seed 42             # 화면 없이 게임 3일 돌리기
node tools/headless.js --days 10 --seed 7 --bots 3    # 봇 3명
node tools/economy.js --days 60 --seed 7              # AI 개척민 섬 경제 점검 (--bots 1, --json 가능)
node tools/combat.js --trials 30                      # 헤드리스 결투: 장비·실력별 승률 (--foes raider,raider_captain · --site camp · --gap 레벨차)
python3 -m http.server 8000                           # http://localhost:8000 에서 게임 열기
node server/index.js --port 8787                      # 멀티 시험 서버(2~8인). http://localhost:8787/?server=auto&name=이름
```

멀티 시험(v3.0): 서버가 화면도 함께 내준다. 같은 망의 다른 기기는 `http://서버주소:8787/?server=auto&name=이름`으로 붙는다.
다른 곳에 올린 화면에서 붙을 땐 `?server=서버주소:포트`를 쓴다(https 페이지에서는 wss 주소가 필요하다).
서버는 섬을 `server/world.json`에 1분마다, 닫을 때 저장한다. `--world 경로`, `--seed 숫자`로 바꾼다.

Node 18 이상. 코어와 도구는 외부 패키지가 없다.
화면은 `vendor/three/`에 묶어 둔 Three.js r187(MIT)과 그 애드온(하늘·후처리)을 쓴다. 빌드 단계는 없다.
시험할 때는 `?seed=7&fresh`를 붙이면 세이브를 무시하고 정해진 섬을 새로 연다. `&nowarm`은 섬 미리 그리기를 건너뛴다(소프트웨어 렌더러 시험용).
화질은 설정 창에서 자동·높음·중간·낮음을 고른다(브라우저에 기억한다).

## 조작

- PC: WASD 이동 · 마우스 끌기 시점 · 휠 거리 · E 상호작용·대화 · J 일지 · H 귀환 · V 탈것 · I 가방 · C 제작 · K 스킬 · L 기록 · Esc 닫기
- 거래소(마을 서쪽 좌판)·마을 게시판(주문·마을 사업·산지 소문)·대장간(제작·수리)은 앞에 서서 E로 연다
- 정착지(v0.4): 등대 마을에서 북쪽 길 끝이 숲머리다. 창고·거래소·게시판은 마을마다 따로다. 가방 창의 🚚로 다른 마을 창고에 보내고, ‘귀환 지점으로’로 귀환할 마을을 정한다
- 전투(v0.3): 왼쪽 클릭 약공 · 길게 눌렀다 떼면 강공 · 오른쪽 버튼이나 Q 막기 · Space 구르기 · 쓰러뜨린 짐승 앞에서 E 손질. 휴대폰은 ⚔️🛡️🌀 단추
- 퀘스트(v0.5): 왼쪽 위 추적 줄과 금빛 화살표가 지금 할 일을 가리킨다. NPC 머리 위 `!`·`?`에 다가가 E로 대화한다. 현상금은 마을 게시판 ‘현상금’ 탭에서 받는다
- 적(v0.5): 검은 돛 약탈단은 막기를 쓴다(강공으로 깬다). 머리 위 붉은 ‼는 센 공격, ⛔는 막을 수 없는 공격이다. 밤에는 마을 사이 들판에 안개 늑대가 나온다
- 2장(v0.5.1): 안개 망령은 떠다니며 할퀴고 날아든다. 옛 등불터의 돌 해태는 「돌 해태」 퀘스트를 받아야 깨어난다. 줄거리는 `docs/story.md`
- 등대섬(v0.5.2): 1~2장은 튜토리얼 섬이다. 퀘스트를 따라가면 생활과 전투를 하나씩 익힌다. 주문·마을 사업·운송·산지 소문은 3장, 세력·PvP·원정은 4장에서 열린다(일지 '생활 안내' → '열리는 것')
- 본섬(v0.6): 3장에서 배를 고쳐 안개 벽 너머 갈대 나루로 건너간다. 돌아올 수 없고, 창고 짐은 따라간다. 큰 장터·주문·마을 사업은 본섬에서 열린다
- 세력(v0.7): 4장에서 등불단·자유 선단·안개 학회 가운데 하나를 고른다. 지도자 의뢰와 그 세력다운 생활로 영향력을 쌓으면 등급마다 생활 혜택이 붙는다
- 내 집(v0.8): 본섬 집터에 오두막을 지어 큰 집까지 올린다. 가구로 아늑함을 쌓아 쉬면 숙련 경험이 오르고, 텃밭에서 산딸기·버섯·갈대를 기른다
- 등급 색과 종결 장비(v3.3): 일반·고급·희귀·영웅·전설 색, 심장 등급·원정 이름난 물건, 귀걸이까지 장신구, 탈것 4티어, 트로피·집 길잡이 돌
- 제작 숙련 계수(v3.3.1): 갓 배운 장비는 일반부터, 레벨이 오를수록 높은 등급
- 길잡이 돌과 탈것(v3.2): 마을·쉼터 16곳 길잡이 돌로 건너뛰기, 마구간에서 산 탈것을 V로 불러 타기, 안장·편자
- 서브퀘스트와 레벨 난이도(v3.1): 서브퀘스트 18개, 퀘스트마다 권장 레벨과 색, 레벨 차이가 피해에 들어간다
- 멀티 시험(v3.0): Node 서버 하나에 2~8명이 붙어 같은 섬을 돈다. 서로 보이고 말할 수 있다
- 영지전(v2.7): 조합으로 본섬 마을에 선전포고하고 전쟁 물자를 모아 공성으로 깃발을 차지한다. 영지는 세금·수수료 혜택을 준다
- 필드 PvP(v2.6): 깃발을 올리거나 분쟁 구역에 들면 다른 세력 개척자와 겨룬다. 쓰러지면 재료 일부를 빼앗긴다
- 소리(v2.5): 생활·싸움 효과음, 파도·바람·새·풀벌레 환경음, 지역·밤·싸움에 따라 바뀌는 배경 음악

- 원정과 전투 레벨(v2.3): 전투 레벨·능력치, 원정 넷과 동료, 설계도로 만드는 안개강 장비
- 안개 속 등불(v2.0): 고운 글꼴과 금빛 테의 창, 둥근 지도, 대화 초상화와 대화 카메라, 계절 입자(꽃잎·반딧불·낙엽·눈), 빛내림

## 지키는 규칙

1. 모든 행동은 명령이다. 화면과 AI는 상태를 직접 고치지 않는다.
2. 상태는 그대로 JSON이 되는 순수 데이터다. 장애물 격자처럼 상태에서 나오는 값은 저장하지 않는다.
3. 난수는 코어의 시드 RNG만 쓴다. 시드가 같으면 결과도 같다.
4. 재료 차감과 결과 지급은 한 번에 끝낸다.
5. 데이터 구조가 바뀌면 `core/save.js`에 마이그레이션을 더한다.
6. 페이지는 검색에 노출하지 않는다. 새 HTML에도 `<meta name="robots" content="noindex, nofollow, noarchive">`를 넣는다.
   robots.txt로 막지 않는다. 막으면 검색엔진이 이 태그를 읽지 못한다.
7. 패치마다 페르소나 자동 플레이를 돌리고, 결과를 패치노트 후기와 `docs/playtests/`에 남긴다.
